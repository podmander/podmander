# Issue tracker: Forgejo

Issues for this repo live in [Forgejo](https://code.monospacementor.com/podmander/podmander). Use the Forgejo MCP server or the `fgj` CLI for operations the MCP server does not support.

## Conventions

- Owner: `podmander`
- Repo: `podmander`
- Infer the repo from `git remote -v`.

## Labels

- **In progress:** (organization level) -- Assign when actively working on an issue.

For triage labels, see `triage-labels.md`. 

## When a skill says "publish to the issue tracker"

Use the Forgejo MCP server to create an issue.

## When a skill says "fetch the relevant ticket"

Use the Forgejo MCP server to retrieve the issue with all its comments.

## When a skill or the user say "submit a pull request"

Use the Forgejo MCP server to submit a pull request.
